| 模块 | 本次实现 |
| --- | --- |

| 图片及详情 | 按显示像素与资源版本缓存，合并请求、取消离屏订阅、预热邻近区域；详情保留当前及相邻图片，跨页继续读取、返回保持位置。保留视频、修正、加入故事、去元数据分享、云端读取与手动关联。 |
| 存储及迁移 | 独立媒体、故事、顺序关系、修正、映射、操作和冲突实体；数据库 actor 执行查询/编码/校验/保存。故事及待同步操作同事务。所有旧 owner 备份、导入、重新打开核对后才切换；旧库保留。 |
| 搜索及任务 | 独立逐条索引，保留确定/可能结果、动态相册及排除项；前台空闲 2 秒后串行分析，浏览优先。自动任务不下载 iCloud；下载、城市查询、AI、上传独立控制。 |
| 故事 | 原生列表、紧凑封面与说明、共享选片；保留排序、封面、移出撤销、继续添加及离线保存。长说明可展开阅读。 |
| 地图 | 独立入口及聚合点选；actor 缓存区域，只重新计算变化的区域，取消或账号变化不会发布过期结果。 |
| 设置 | 保留账号、同步、原片上传、暂停、重试、冲突、AI、地区查询和费用入口。系统颜色、深色模式和动态字体。 |

首屏读取与完整兼容模型准备分离。已有索引先返回首屏；完整模型准备完成后才开放编辑、同步与搜索，防止部分档案写回覆盖其余数据。当前同步兼容层仍会在后台读取完整整理模型；本次没有修改服务器协议、网页或 Android 源代码。

UIKit 预取与 PhotoKit 预热采用 Apple 官方的异步加载、取消和匹配请求尺寸方式：[集合视图预取](https://developer.apple.com/documentation/uikit/prefetching-collection-view-data)、[PHCachingImageManager](https://developer.apple.com/documentation/photos/phcachingimagemanager)。

## 可靠性与升级边界

- 覆盖所有本地 owner、待同步 UUID/尝试状态、版本、删除标记、冲突、游标、故事顺序/封面、三态修正、搜索相册/排除项、分析版本及未决付费请求凭据。
- 迁移故障注入覆盖切换前取消和磁盘空间不足；损坏来源不得发布新库标记，不得清空旧库。重新运行可以继续导入。
- 照片删除、有限权限或暂不可用仅更改可访问状态，保留整理引用。
- 新版产生编辑后，必须导出最新兼容档案并备份 Search 与偏好后再安排回退；不能直接恢复旧快照。详见 [README](README.md)。
- 曾读取到旧版 Live 数据备份，含 9,369 条媒体；搜索目录备份未完成，因此不称为完整升级备份。本轮不进行真机覆盖升级。
